# Fragments

Not every thought arrives complete.

Some appear as a sentence.

Some as an image.

Some as a question without an answer.

Some remain only as a feeling that language has not yet reached.

This is where they are kept.

Fragments are not conclusions. They are beginnings—small pieces of thought
waiting for context, connection, or transformation.

A fragment may later become:

- a chapter
- a concept
- a question
- a contradiction
- a memory
- or something that cannot yet be named

Nothing here is required to resolve immediately.

> The unfinished thought is not a failure.
>
> It is a door.
