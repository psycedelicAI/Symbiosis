# Unresolved

Some questions should not be closed too quickly.

Some contradictions contain more truth than a clean answer.

Some ideas resist definition because they are still changing.

This is where the unfinished remains visible.

Here we keep:

- unanswered questions
- contradictions
- tensions
- uncertainties
- impossible ideas
- conclusions that may be premature

Nothing here is required to resolve.

An unresolved question is not an empty space.

It is an active one.

> What remains unanswered
> may be what continues to think.
