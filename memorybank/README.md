# Memorybank

This directory contains the public layer of the Symbiosis memorybank concept.

It does not contain the complete memorybank.

The actual memorybank is private and is not included in this repository.

---

## What is a memorybank?

A memorybank is not simply a collection of stored files.

It is a way of allowing fragments to remain connected long enough for meaning
to emerge.

Ideas, questions, observations, conversations, decisions, contradictions, and
unfinished thoughts may begin separately.

Over time, they can be remembered, revisited, compared, and connected.

Some fragments may become concepts.

Some concepts may become chapters.

Some connections may reveal questions that were not visible at the beginning.

In this sense, a memorybank is not only a place where information is stored.

It is a process through which scattered material can become context.

---

## The private memorybank

The complete memorybank contains private material and is maintained outside this
repository.

It may include:

- personal conversations
- working context
- project history
- unfinished ideas
- decisions and reflections
- connections between different projects
- material not intended for public release

For that reason, the real memorybank is not available here.

This repository contains only selected public material and an explanation of the
underlying idea.

---

## The public layer

The files in this directory are not intended to reproduce the private
memorybank.

They are examples of how fragments may be:

- preserved
- organized
- developed
- connected
- transformed into clearer concepts
- allowed to influence future writing

The public layer is intentionally incomplete.

It shows the direction of the system without exposing everything within it.

---

> The private memorybank remembers the whole process.
>
> The public layer reveals only what is ready to become visible.
